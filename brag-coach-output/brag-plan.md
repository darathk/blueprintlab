# Brag Plan: BlueprintLab

## 1. Core Decisions
* **Angle**: The ultimate command center for strength coaches.
* **Hook**: "Coach smarter, not harder." (or visually: dark glass UI opening up to a powerful dashboard).
* **Key Moments**: 
  1. The coach's active dashboard (Athlete Cards).
  2. Deep dive into an athlete's analytics (Charts).
  3. Meet Day Attempt Strategy (Calculations).
* **Outro**: "BlueprintLab. Deploy."
* **Tone**: `polished`
* **Duration Strategy**: ~18-20s. Snappy UI highlights.
* **Format**: Landscape (16:9) by default.

## 2. Visual Identity (from src/app/globals.css)
* **Background**: #0a0a0a with #7d87d2 radial glow.
* **Primary**: #7d87d2
* **Secondary**: #a855f7
* **Success**: #10b981
* **Font**: Inter, system-ui

## 3. Scene Storyboard
1. **Scene 1: The Command Center (0-5s)**
   - Text: "The modern coach's command center."
   - Visual: Grid of glassmorphism athlete cards sliding in.
2. **Scene 2: Advanced Analytics (5-11s)**
   - Text: "Real-time fatigue & E1RM."
   - Visual: Analytics charts (DotsChart, FatigueChart) animating in.
3. **Scene 3: Meet Day Strategy (11-16s)**
   - Text: "Automated attempt selection."
   - Visual: The Attempt Sheet interface calculating 9/9 totals.
4. **Scene 4: Outro (16-19s)**
   - Text: "BlueprintLab."
   - Visual: Logo/brand lockup, fade to black.
